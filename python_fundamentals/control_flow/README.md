# Python - Flujo de control

Control flow fundamentals: conditionals (`if`/`elif`/`else`), comparison
and boolean operators, `while` loops, and `for` loops using `range()`.

## Tasks

0. `positive_or_negative.py` - classify a random integer as positive,
   zero, or negative.
1. `last_digit.py` - compute and classify the last digit of a random
   integer.
2. `print_alphabt.py` - print the lowercase alphabet except `q` and `e`.
3. `print_hexa.py` - print 0 to 98 in decimal and hexadecimal.
4. `print_comb2.py` - print 00 to 99, comma-separated.
5. `print_comb3.py` - print all unique ascending two-digit combinations.
