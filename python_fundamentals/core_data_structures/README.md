# Python - Core Data Structures

Core built-in data structures: lists, tuples, sets, and dictionaries.
Focuses on safe access, edge-case handling (empty inputs, out-of-range
indices, missing keys), and choosing the right structure for the job.

## Tasks

0. `print_list_integer.py` - print all integers of a list, one per line.
1. `element_at.py` - safe list access, returns None out of range.
2. `replace_in_list.py` - replace a list element at a given index.
3. `print_matrix_integer.py` - print a 2D list, row by row.
4. `add_tuple.py` - add two tuples, missing values treated as 0.
5. `common_elements.py` - set intersection of two sets.
6. `update_dictionary.py` - add or update a key/value pair.
7. `best_score.py` - return the key with the highest value.
