# Python - Classes & Object Model

Introduction to the Python object model: defining classes, creating
instances, encapsulating state with private attributes, validating
input, exposing controlled access with properties (getters/setters),
and implementing string representations with `__str__`.

## Tasks

1. `0-square.py` - a minimal `Square` class with no attributes or
   methods.
2. `1-square.py` - `Square` with a private instance attribute `size`.
3. `2-square.py` - `Square` with a validated `size` (raises on bad
   type or negative value).
4. `3-square.py` - `Square` with an `area()` instance method.
5. `4-square.py` - `Square` with a `size` property (getter/setter)
   for controlled, validated access.
6. `5-square.py` - `Square` with `my_print()`, rendering the square
   with `#`.
7. `6-square.py` - `Square` with a `position` property and `__str__`,
   printing the square offset by position.
8. `1-rectangle.py` - `Rectangle` with private, validated `width` and
   `height` properties.
9. `2-rectangle.py` - `Rectangle` with `area()` and `perimeter()`.
