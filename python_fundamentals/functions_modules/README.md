# Python - Functions & Modularity

Function definitions, return values vs print, ASCII-based string logic,
manual exponentiation, and Python's import/execution model
(`if __name__ == "__main__":`).

## Tasks

0. `islower.py` - check if a character is lowercase, via ord().
1. `uppercase.py` - print a string in uppercase, via ord()/chr().
2. `print_last_digit.py` - print and return a number's last digit
   (always positive).
3. `pow.py` - compute a ** b manually with a loop, no ** operator.
4. `simple_add.py` / `test_import.py` - demonstrate the __main__ guard.
5. `add.py` / `add_0.py` - import and call a function from another file.
6. `calculation.py` / `calculator_1.py` - import multiple functions.
7. `variable_load.py` / `variable_load_5.py` - import a variable.
